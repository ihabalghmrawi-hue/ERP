# 📊 BOB ERP — نظام المحاسبة وإدارة الأعمال المتكامل

نظام ERP متكامل مبني بـ **Next.js 14 + TypeScript**، يدعم اللغة العربية بالكامل (RTL) مع نظام i18n ديناميكي.

---

## 🚀 تشغيل المشروع

### المتطلبات
- **Node.js** الإصدار 18 أو أحدث
- **npm** أو **yarn**

### الخطوات

```bash
# 1. انتقل إلى مجلد المشروع
cd nexus-erp

# 2. ثبّت الحزم
npm install

# 3. شغّل خادم التطوير
npm run dev

# 4. افتح المتصفح على
http://localhost:3000
```

عند أول تشغيل سيظهر **شاشة إعداد النظام** لإنشاء حساب المدير.

## 📋 خطوات البدء السريع (بعد التشغيل)

بعد إنشاء حساب المدير، اتبع هذا الترتيب:

### 1. إضافة دليل الحسابات (المحاسبة → دليل الحسابات)

أضف الحسابات الأساسية التالية:

| الكود | الاسم | النوع | الفئة |
|-------|-------|-------|-------|
| 1010 | الصندوق الرئيسي | asset | current_asset |
| 1100 | الذمم المدينة | asset | current_asset |
| 1200 | المخزون | asset | current_asset |
| 2000 | الذمم الدائنة | liability | current_liability |
| 2200 | ضريبة المبيعات | liability | current_liability |
| 3000 | رأس المال | equity | equity |
| 4000 | إيراد المبيعات | revenue | revenue |
| 5000 | تكلفة البضاعة المباعة | cogs | cogs |
| 6000 | المصاريف التشغيلية | expense | expense |

### 2. إضافة مستودع (المخازن)
انقر **"+ مستودع جديد"** وأدخل اسم المستودع.

### 3. إضافة منتجات (المخازن)
انقر **"+ منتج جديد"** مع تحديد:
- سعر التكلفة
- سعر البيع
- نسبة الضريبة (%)
- حد إعادة الطلب

### 4. إضافة عملاء وموردين
من قسمَي **العملاء** و**الموردين**.

### 5. البدء بالفوترة
من قسم **المبيعات** أو **المشتريات**.

> ✅ كل فاتورة تولّد قيدًا محاسبيًا تلقائيًا وتحدّث المخزون فوراً.

## ⚡ آلية القيود التلقائية

### فاتورة مبيعات (آجل)
```
DR  الذمم المدينة (1100)          ← إجمالي الفاتورة
  CR  إيراد المبيعات (4000)         ← المبلغ قبل الضريبة
  CR  ضريبة المبيعات (2200)         ← مبلغ الضريبة
DR  تكلفة البضاعة (5000)          ← تكلفة FIFO
  CR  المخزون (1200)                ← تكلفة FIFO
```

### فاتورة مبيعات (نقدي)
```
DR  الصندوق (1010)                ← إجمالي الفاتورة
  CR  إيراد المبيعات (4000)         ← المبلغ قبل الضريبة
  CR  ضريبة المبيعات (2200)         ← مبلغ الضريبة
DR  تكلفة البضاعة (5000)          ← تكلفة FIFO
  CR  المخزون (1200)                ← تكلفة FIFO
```

### أمر شراء
```
DR  المخزون (1200)                ← إجمالي الأمر
  CR  الذمم الدائنة (2000)          ← إجمالي الأمر
```

## 🌍 نظام اللغات (i18n)

- التبديل من **الإعدادات** → اللغة
- دعم كامل لـ **RTL** (عربي) و **LTR** (إنجليزي)
- جميع النصوص في ملف واحد: `src/lib/i18n/translations.ts`

لإضافة لغة جديدة:
```typescript
// src/lib/i18n/translations.ts
export const TRANSLATIONS = {
  ar: { ... },
  en: { ... },
  fr: { ... },  // أضف هنا
};
```

## 💾 قاعدة البيانات

البيانات محفوظة في **localStorage** — تبقى عند إغلاق المتصفح.
